# Memory Index

## 项目摘要

- 类型：2D 纯竖屏移动端休闲游戏。
- 核心体验：全天候离线挂机，上线领取收益，下线持续成长。
- 操作方式：适配手机单手操作。
- 技术方向：UrhoX Lua，用户代码应放在 `scripts/`。

## 不可变规则

1. 所有玩家数据登录游戏时请求存档。
2. 游戏中改变了玩家存档数据时请求更新存档。
3. 纯竖版适配，不支持横屏，UI、场景、战斗视角全部为竖屏定制。
